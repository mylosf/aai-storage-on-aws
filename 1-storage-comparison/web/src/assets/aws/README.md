# AWS Architecture Icons

The SVGs in this folder are unmodified files from the official **AWS Architecture Icons**
asset package, release 07/31/2026 (https://aws.amazon.com/architecture/icons/).

- `Arch_*_48.svg` — service icons (EC2, EBS, EFS, FSx variants, S3, S3 Glacier, CloudFront, Systems Manager)
- `Res_*_48.svg` — resource icons (EC2 instance, general Client / User / Application)

They are used here only to depict AWS services in architecture diagrams, which is the use
AWS grants in the icon package's terms. Keep the original filenames so the source is traceable.
