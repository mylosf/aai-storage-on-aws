# AWS Architecture Icons

The SVGs in this folder are unmodified files from the official **AWS Architecture Icons**
asset package, release 07/31/2026 (https://aws.amazon.com/architecture/icons/).

- `Arch_*_48.svg` — service icons (S3, S3 Glacier, Lambda, EventBridge, DynamoDB, CloudWatch, CloudFront)
- `Res_*_48.svg` — resource icons (S3 bucket, object, replication, Batch Operations; general Client / User / Application)

They are used only to depict AWS services in architecture diagrams, the use AWS grants in the
icon package's terms. Keep the original filenames so the source is traceable.
